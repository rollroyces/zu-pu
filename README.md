# 族譜 / zu-pu

> 在哪裡出生，曾經不是我們能選的——這套工具至少讓記錄這件事可以。

通用族譜工具：選出生地、新增編輯刪除、祖上/子孫/時間軸多視角、GEDCOM 5.5.1 匯入匯出。
Vanilla HTML/CSS/JS，零依賴、無 build step，資料放在 localStorage（不上傳任何伺服器）。

## 線上版

<https://frvzq8mtuxgx4.space.mcode.cn>

## 本地跑

```bash
python3 -m http.server 8766
# 然後開 http://localhost:8766
```

或任何靜態伺服器都行（`npx serve`、Nginx、Cloudflare Pages⋯⋯）。`file://` 直接打開會被瀏覽器擋 `fetch`。

## 功能

- **族譜樹**：祖上圖（向上展開）、子孫圖（向下展開）、祖上＋子孫
- **名冊**：所有成員卡片列表，支援搜尋、依世代/出生/姓名排序
- **時間軸**：依出生年、逝世年展開
- **新增 / 編輯 / 刪除**：完整 CRUD，含父母、配偶、子女、日期、地點、備註
- **搜尋**：依姓名、英文名、出生/逝世地、備註
- **GEDCOM 5.5.1 匯入匯出**：可與 Gramps、MyHeritage、Ancestry、RootsMagic 等家譜工具互通
- **localStorage 持久化**：關閉瀏覽器再開資料還在
- **重置 / 清空**：內建「重置為範例資料」與「清空全部」按鈕

## 真實資料

30 個國家的真實公開統計（World Bank、UN WPP 2024、WHO GBD、UNDP）— 不對，這是族譜 app，沒有國家資料。
這裡用的是 30 個人的人生資料（含出生年、逝世年、出生地、職業關係、伴侶、子女等）。

## 資料模型

每位成員：
- 基本：姓名（中英）、性別、出生/逝世日期與地點、備註
- 關係：父母（最多兩位）、配偶（可多位，順序 = 重要性/正室）
- 衍生：子女（從父母反推）、兄弟姊妹（共享父母者）、岳父/岳母（從配偶反推）

父母關係是任一性別的單獨撫養或多性別配偶關係都可表達。

## 族譜樹繪製

- **祖上圖**：把自己放在最下方，父母、祖父母⋯⋯按 2^n 個欄位往上展開，標準族譜格式
- **子孫圖**：把自己放在最上方，子女、孫子女⋯⋯按代往下展開，縮排式

兩者皆用 SVG 渲染，每代節點是一張小卡片（性別顏色邊框、姓名、生卒年、已故用虛線）。

## GEDCOM 處理

- 內部模型：每位成員有 `parents` 與 `spouses` 陣列
- GEDCOM 模型：每位成員有 `FAMS` 與 `FAMC` 指向 `FAM` 記錄
- 轉換規則：
  - 兩個有共同子女的父母 = 一個 FAM（HUSB + WIFE + 共同子女）
  - 子女的 parents 列表用於建立 FAM
  - 額外配偶（無共同子女）也建 FAM
  - 單親：FAM 只列 HUSB 或 WIFE
- 中文姓名處理：把「張守正」拆成「守正 /張/」（given /surname/），符合國際慣例

## 設計選擇

- 紙本書卷風：米色背景、暗紅色（#b03a3a）強調、襯線中文字型
- 男藍（#4a6da8）、女粉（#b86998）：用顏色區分性別
- 已故用虛線邊框 + 較低不透明度
- 響應式：桌機、手機皆可
